- **关键坑 & 修复（务必记住）**：
  1. **测试 fakePlatforms 包装器曾吞掉 sessionId**：`getSession: async (_dir, sid) => d.getSession(sid)` 只传一个参数，导致两条 session 拿到同一份 waiting_input 消息、sessionId 错位 → 2 例失败。修正为转发 `(dir, sid)` 后 10/10 通过。
  2. **聚合器首屏极慢（~9.5s）**：`collectActiveSessions` 串行扫 9 个平台目录，其中 codex 5s / openclaw 1.2s / doubao 0.5s。修复 = ① `Promise.all` 并行枚举；② 枚举结果按 platform-set 引用 + 30s TTL 缓存（WeakMap+createCache），热路径 ~39ms→0ms；③ 每 session 状态仍每轮实时重算（只缓存「活跃列表」，不缓存状态）。
  3. **hermes 平台 `list` 是同步函数**（返回 array 而非 promise）：原 `platform.list(dir).catch(...)` 抛 `is not a function`，hermes 被静默丢弃。改 `Promise.resolve(platform.list(dir)).catch(()=>[])` 兼容同步/异步两种契约。
  4. SSE 连接瞬间先发一帧 idle 占位（`lastKey` 预置），让 widget 立刻显示「已连接」；真实 top-1 算出后若非 idle 即覆盖。
