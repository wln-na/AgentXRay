## 关键架构决策（各有理由，勿轻易回退）
1. **只有 `main.js` / `preload.js` 可 `require('electron')`**；`desktop/lib/**` 全是纯模块，能被根 `node --test` 覆盖 —— 沙箱装不了 Electron，这是唯一可 CI 化的边界。
2. **SSE 放主进程**（renderer 是 `file://`、Origin=null，跨源会被拦），经 IPC 推给 renderer。
3. **N4 守住**：Electron 只在 `desktop/package.json` 的 `optionalDependencies`；根 `package.json` 的 `dependencies`/`files` **一字未动**；不改根 `bin/`。
4. **点击穿透仅 macOS**：`forward:true` 是 macOS 专有语义；非 darwin 一律不穿透（否则 renderer 收不到 pointer → 宠物永久点不动）。
5. **不用全局快捷键做安全阀**：裸 `Escape` 注册为系统级热键，要么注册失败、要么劫持全系统 Esc → 改 renderer 本地 `keydown` + `blur` + 5s 空闲阀。
6. **own-server 必须用「真 node」**：`server.js` 经 `lib/routes/search` → `lib/search-index.js`、`lib/platforms/{hermes,doubao-store}.js` **顶层** `require('better-sqlite3')`，用 Electron 内置 Node（ABI 与系统 Node `modules=127` 不同）跑会启动即崩。`lib/node-exec.js` 解析顺序：`AGENTXRAY_PET_NODE` → `which node` → `npm_node_execpath` → Electron 回退（**带 warning**）。
7. 子进程 stdout/stderr **接管道落盘** `~/.agentxray/pet/{pet,pet-err}.log` —— 原 `stdio:'ignore'` 会把崩溃原因全吞掉。

## 修过的真 bug（多为审出来、测试覆盖不到的）
1. `decideWatchdog` 规则 1：宽限分支**无时间上界且无 `childAlive` 门控** → **启动即崩永不重启**，直接打穿 P3「崩溃自拉」。修法：加 `startedAt` + 改三条件与。**设计稿 §3.2 同源缺陷**（规则引用了签名里不存在的字段）已一并修订。
2. `sse.js` **CRLF 跨 chunk 误分帧**：`feed()` 里全局 `.replace(/\r/→\n)` 把缓冲尾部孤立 `\r` 当空行 → 事件被切碎、真数据被当未知 `message` 丢弃。修法：保留原始 buffer + `EVENT_SEP=/\r\n\r\n|\n\n|\r\r/`。**已用穷举切分点验证：全 32 个切分点 0 不一致。**
3. 测试桩 `getSession: (_dir,sid) => d.getSession(sid)` 吞掉 sessionId → 2 例断言错位（生产代码本身正确，是桩的锅）。
4. （P1 期）hermes 平台 `list` 是**同步**函数，`.catch()` 抛错 → 平台被静默丢弃。
5. （P1 期）首屏聚合 ~9.5s → 并行枚举 + 30s 枚举缓存，热路径 ~0ms。

## 已知限制（非缺陷，勿误修）
- `EVENT_SEP` 只认**同风格** `\n\n` / `\r\n\r\n` / `\r\r`；跨风格 `\n\r`、`\n\r\n`、`\r\n\r` 会丢帧。
  **绝对不要用 `/(?:\r\n|\r|\n){2}/` 去修** —— 正则回溯会把**单个 CRLF** 拆成 `\r`+`\n` 两个 token 当成空行；实测 `'event: state\r\ndata: x\r\n\r\n'.split(该正则)` 得 **3 段**（应为 1 条），采纳即回归。真要加固用「**贪婪行结束符分词器**」（先消费 `\r\n`，再消费孤立 `\r`/`\n`；空行 = 连续两个 token）。后端只发 LF → 当前不可触发。
