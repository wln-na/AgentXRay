# 2026-10-27

## WorkBuddy / Trae 会话在 AgentXRay UI 里不展示（前端平台清单缺口）

**现象**：后端 `/api/workbuddy/sessions` 正常返回 111 条、`/api/trae/sessions` 返回 6 条，
但 Web UI 上没有 WorkBuddy / Trae 入口，会话完全看不到。

**根因**：前端平台清单是硬编码的 `frontend/src/api/types.ts` 里的 `Platform` 联合类型 +
`PLATFORMS` 数组 + `PLATFORM_LABELS`，与后端 `lib/platforms/index.js` 的 `PLATFORMS`
注册表各自维护。PR #26 只把 workbuddy/trae 接进了后端注册表与 pet 聚合，
前端清单停留在 10 个平台（缺 workbuddy、trae），所以 UI 无从渲染。

**修复**（只动前端 + 展示层剥离，后端适配器本来就完整）：

- `api/types.ts`：`Platform` 加 `workbuddy` / `trae`，补 `PLATFORMS` 与 `PLATFORM_LABELS`。
- `api/client.ts`：`DirSettings` 加 `workbuddyDir` / `traeDir`。
- `store.ts`：`EMPTY_SETTINGS`、`dirForPlatform` 的两个 case、`loadPersisted` 回填。
- `components/PlatformBar.tsx`：`PLATFORM_TIPS` 补两条（`Record<Platform,string>` 必填，
  漏了会 tsc 报错——这也是这类清单最好的自动防线）。
- `components/SettingsDialog.tsx`：`DIR_FIELDS` + `save()` 补两个目录字段。
- `views/sessions/CmdkDialog.tsx`：`PLAT_BADGE` 颜色（WorkBuddy `#0052d9`、Trae `#ff5a1f`）。
- `views/sessions/SessionSummary.tsx`：`RESUME_PLATFORM_TITLES` 两条 open 提示。
- `views/help/HelpView.tsx`：`DEFAULT_DIRS` 补两行。

**顺带的可读性修复**（`lib/platforms/workbuddy.js`）：WorkBuddy 把 `<system-reminder
data-role="user-context">`（含 user_info/workspace/skills 清单）整块塞进 user 消息，
导致列表预览每条都是同一坨注入文本、完全无法区分。新增
`stripWorkbuddySystemReminders()`（照 `lib/platforms/claude.js:148` 的先例），
仅用于提取 `firstUserMessage`：剥离 system-reminder 块（正则要容忍带属性开标签
`<system-reminder\b[^>]*>`）+ 去掉 `<user_query>` 纯包装标签；剥完为空则跳过该条
继续找下一条真实提问。消息正文保持原始记录不动。

**测试**：`test/workbuddy.test.js` 加 strip 单测 + 列表预览断言；fixture 0002 前置
插入一条「纯注入」user turn（不新增 fixture 文件——`test/api.test.js` 的 backup 用例
硬编码了 fixture 文件总数 29，多一个文件就会挂）。全量 `npm test` 598 项通过，
改动文件 `biome check` 0 error。

**坑记**：`public/js/pure.js` 由 `npm run build:ui` 生成，CI 会 `git diff --exit-code`
检查漂移；本次只改 tsx/ts 与 lib，生成物无漂移。
